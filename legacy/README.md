# Deprecated sources

Electron is the supported ZeroCollab application. The browser frontend and independent terminal launchers are deprecated; the root `Start-Room` entry starts Electron and Quit closes its owned backend.

`launchers/` preserves the old Windows and macOS/Linux wrapper launchers for reference. They are not installed, tested or maintained as alternate product entrypoints. Their old relative paths are intentionally not a supported setup path. Current managed native providers live in `src/zerocollab/providers/`.

`release-manifests/` preserves historical donor receipts. Current desktop resources are generated by `scripts/prepare_desktop.py` into ignored `build/desktop/` from canonical source. Existing runtime data, installations, archives and worktrees were not moved or deleted in this cleanup.
